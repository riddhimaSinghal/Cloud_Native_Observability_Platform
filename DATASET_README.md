# Simulated Cloud Infrastructure Metrics Dataset

Synthetic server metrics generated by the simulator in the project (`backend/app/collector.py`).

- Files: `simulated_metrics.csv` (5,000 rows, 5-second intervals, seed 42)
- Columns: timestamp (UTC), cpu_percent, memory_percent, disk_percent, net_in_kbps, net_out_kbps,
  label (`normal` / `fault`), scenario (`none`, `cpu_spike`, `memory_leak`, `disk_fill`, `network_flood`, `full_failure`)
- Fault episodes last 20 samples and are separated by healthy stretches.
- Reproduce: `cd backend && python export_dataset.py --rows 5000 --seed 42`
- Limitation: data is simulated, not collected from real production servers; labels are ground truth for the simulation only.
